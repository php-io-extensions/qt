# Agent guidance — php-io-extensions/qt

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C++, or packaging. Open only the concepts the change touches.
2. **Qt, 1:1.** One PHP method = one native call (Qt 6: QtCore, QtGui, QtWidgets, QtOpenGLWidgets, QtMultimedia), under its native name and signature: `QWidget::setWindowTitle(const QString &)` → `QWidget::setWindowTitle(string $title)`. A C++ scope is a PHP namespace (`QTextEdit::ExtraSelection` → `QTextEdit\ExtraSelection`, `Qt::WindowType` → `Qt\WindowType`). An overload set binds the overload the native name keeps; defaults are the native ones. Qt's value classes (`QPoint`, `QPointF`, `QSize`, `QRect`, `QDate`, `QKeySequence`, `QUrl`, `QByteArray`, …) are PHP value objects holding a copy, never arrays or strings. A native nullptr is `null`. Qt's behaviour passes through: invalid values, false, nullptr and qWarning output reach PHP as Qt produces them. See [`.okf/api/surface.md`](.okf/api/surface.md).
3. **Refusals.** The rule, verbatim:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   Qt has no error object to translate: a qWarning is a log and passes through; a qFatal is process death (outcome 2). Kept refusals throw `QtException` (or a ValueError where an argument is the cause): [`.okf/architecture/errors-and-threads.md`](.okf/architecture/errors-and-threads.md).
4. **Glue** is the only native code beyond the calls: the trampolines Qt calls back through (the signal slot `PhpSlot`, `QEventFilter`'s `eventFilter(watched, event)`, `QOpenGLPainter`'s `paintGL`, `QImage`'s cleanup function, the `QTimer::singleShot` functor), value marshalling (PHP ↔ QVariant, enums, value classes, string and int lists, argv, fds), wrapper lifetime, and the pointer hand-off. Each forwards the native arguments it receives and returns PHP's result to the native caller, and adds nothing else. The glue classes, as `bindings.json` `glue` names them: `QtException`, `QObject::pointer`, `QMetaObject\Connection::isValid`, `QEventFilter::__construct`, `QOpenGLPainter::__construct`, `QByteArray::pointer`. See [`.okf/architecture/signals.md`](.okf/architecture/signals.md).
5. **Shapes.** A C++ abstract class is a PHP `abstract class`; a constructor only Qt calls is a private one with an empty body; a static-only class keeps a private constructor. A struct with no constructor of its own (`QTextEdit\ExtraSelection`) is a plain object with its fields as typed public properties and an aggregate constructor. `int &argc` is a by-reference int written back after the call. An address (`QImage(int $data, …)`, `QVulkanInstance::setVkInstance()`) is the pointer hand-off: trusted, borrowed, never copied.
6. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against the Qt headers and the stubs; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them. A throw on an added line needs a `/* binding:<id> */` marker naming a site, unless it sits inside a `helpers.marshal` function. One marker marks one line: a second line under the same check needs its own site id.
7. **A kept refusal** reads `if (!PHPQT_PROBE_OFF("<id>") && (<check>))`, carries `/* binding:<id> */` on its throw line, has its `sites` entry in `bindings.json`, and a probe test in `tests/Probes` that shows the crash with the check off (`qtChild()` in `tests/Pest.php`). Probe builds use `./configure --enable-qt --enable-qt-probes`; in that build env `PHPQT_PROBE_OFF=<id>` turns one site's check off and the constant `PHPQT_PROBES` exists. Probe tests skip on release builds. Never ship a probe build. A site that only one platform needs (`main-thread-macos`, `second-application-macos`) compiles out elsewhere.
8. **C++ on the Zend API.** One PHP object per `QObject`, keyed by address and guarded by a `QPointer`: a wrapper whose object Qt deleted throws `QtException` from `phpqt_this` / `phpqt_arg`. PHP deletes what it constructed unless Qt took it through a parent (`phpqt_adopt`). Value wrappers own a heap copy (`phpqt_value_hold`), or borrow one an owner holds (`phpqt_value_borrow`). A second `__construct()` is refused by `phpqt_adopt` / `phpqt_value_fresh`. One `src/<Group>.cpp` per stub; `config.m4` lists the sources and the Qt modules. Qt's floor is 6.4: a member newer than that is `#if QT_VERSION >= QT_VERSION_CHECK(…)`-guarded (see `src/checks/`), a Vulkan declaration `#if QT_CONFIG(vulkan)`.
9. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, commit both. Never hand-edit `*_arginfo.h`. An arginfo with `#if QT_CONFIG(…)` or a `@cvalue` constant is included after the Qt headers. New enums come from `scripts/gen-enum.php`: [`.okf/runbooks/generating-enums.md`](.okf/runbooks/generating-enums.md).
10. **Build.** Mac: `bash install-macos.sh` into Homebrew `php@8.4` (`php84`) and `php@8.4-zts` (`zhp`). Linux: `bash install-debian-trixie.sh`. Pest v4 at `-d memory_limit=128M`, `XDEBUG_MODE=off`, in a logged-in GUI session (`DISPLAY` / `WAYLAND_DISPLAY` on Linux). Run the test files a change touches; gate a commit on the run's exit code. Probe steps: [`.okf/runbooks/build.md`](.okf/runbooks/build.md).
11. **Durable facts go in `.okf`.** Update the matching concept, bump its `generated.at`, append `.okf/log.md`. The bundle documents the package, never a session.
12. **Version** is `PHP_QT_VERSION` in `php_qt.h`: 0.10.1. It moves only past a published tag; tags drive Packagist. `os-families`: linux, darwin.
